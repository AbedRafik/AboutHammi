# Hammi Portfolio

I built this website for my friend Abu Hurairah (Hammi Abou Houraira),
who owns it.


It is a one-page personal portfolio for an app designer and developer,
available in English and Arabic with a full right-to-left layout.

## About

The design and code are the work of Abed Rafik. The project belongs to
Hammi Abou Houraira.

## What is inside

- Two languages, English and Arabic, with automatic right-to-left
  layout switching
- Five sections: hero, about, projects, skills, and contact
- A liquid glass interface over a living fog, with dark and light
  modes
- A fully static site, fast to load and ready to host

## Built with

- Next.js and React
- TypeScript
- Tailwind CSS

## Run it locally

```sh
npm install
npm run dev
```

The site is served at `http://localhost:3000`.

## Build for production

```sh
npm run build
```

For a static export:

```sh
GITHUB_PAGES=1 npm run build
```

The static site is written to the `out` folder.
